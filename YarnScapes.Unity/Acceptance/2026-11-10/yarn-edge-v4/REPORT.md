# 毛线边缘 V4

按讨论顺序落实了四项修改：

1. 方形底板改为下沉的编织支撑层。根据邻格的颜色与完成状态收边或搭接，异色交界使用共享曲线，减少白缝和直角切边。
2. 线股两端弯回底层，并逐渐收拢封口；保留针脚前后交叠。
3. 在外轮廓和异色交界补充细短、弯曲、渐尖的毛丝。毛丝更多沿编织方向散开，相邻格填满后自动减弱，避免内部出现一圈白毛。
4. 对位置、倾角、粗细和高度施加小幅、空间连续的变化。变化由棋盘坐标确定，不随画面移动或重新读取而重新随机。
